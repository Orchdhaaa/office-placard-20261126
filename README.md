One original one-line museum placard for an ordinary office stapler, written as if it were an ancient artifact: "Stapler, c. 1987. Pressed steel, faint rust. Bound a merger, a divorce and one resignation letter, in that order. Donated by a department that no longer exists." Catalogue date, material, a specific imagined history, and a donor, all in 160 characters.

node main.ts
